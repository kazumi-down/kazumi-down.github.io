Kazumi 是什么

一个把“找番、追番、看番”放进同一个应用的开源工具。

Kazumi 的核心思路是“规则驱动”：软件本身不绑定某个固定片源，而是通过用户导入或自己编写的规则，去检索对应视频源里的番剧并调用播放器播放。规则只需最多五行基于 XPath 的选择器，也可以导入他人分享的规则，门槛比较低。项目使用 Flutter 开发，所以 Android、Windows、macOS、Linux 等平台有一致的界面和操作。

播放端支持弹幕（弹幕数据使用弹弹play 开放 API）、倍速、硬件加速和高刷新率适配，并带有追番列表、历史记录、番剧时间表等日常追番所需功能。

Kazumi 主要功能

以下功能均来自官方项目说明，具体以你下载的版本为准。

自定义规则与规则分享

内置规则编辑器，最多五行 XPath 即可构建规则，支持规则导入与分享。

番剧检索与时间表

番剧目录、搜索和每周更新时间表，方便找番和追更。

弹幕与倍速播放

内置播放器支持弹幕显示、倍速、分集播放和字幕。

Anime4K 实时超分辨率

对 GPU 有要求，性能一般的设备可选择效率档或关闭。

追番列表与历史记录

记录追番进度和观看历史，并支持跨设备同步。

投屏与外部播放器

支持无线投屏（DLNA）和外部播放器播放，部分版本还提供一起看、番剧下载与更新提醒。

配色方案

可切换界面配色，适配高刷新率屏幕。

无内置广告

项目本身不插入广告，个别广告来自第三方视频源。

夸克网盘下载与安装教程

三步拿到安装包。

  1. 点击页面上方“夸克网盘下载 Kazumi”，在夸克网盘打开分享页（电脑浏览器或夸克 App 均可）。
  2. 选择与你设备对应的安装包，点击“保存到网盘”，再下载到本地。
  3. Windows 解压后运行；Android 允许安装未知来源应用后安装 APK；macOS 按系统提示打开。
  4. 首次打开后进入“规则管理”，导入规则即可开始检索番剧。

Kazumi 自定义规则怎么用

规则决定了 Kazumi 能检索到哪些视频源。

在应用里打开规则管理，可以导入已有规则，或进入规则编辑器自己写。官方规则仓库欢迎提交规则，并附有规则开发文档。写规则时需要注意：目前仅支持以 // 开头的 XPath 选择器，建议先参照示例规则修改。如果规则能检索但无法播放，可以尝试关闭“使用内置播放器”，改用 WebView 播放以提高兼容性。

常见问题

Kazumi 免费吗？

免费。项目基于 GPL-3.0 开源，仅供个人学习、研究或非商业用途。

为什么有的番剧里有广告？

Kazumi 本身不插入广告，广告来自第三方视频源。建议选择无广告的视频源，也不要相信广告中的任何内容。

开启超分辨率后卡顿怎么办？

超分辨率对 GPU 要求较高。没有高性能独立显卡时，建议选择效率档，或直接关闭。

Linux 版本为什么没有图标和托盘？

tar.gz 版本仅为方便二次打包，天然缺少图标和托盘支持，请改用 .deb 版本安装。

自己编译项目失败怎么办？

编译需要良好的网络环境，除 Google 托管的依赖外，部分依赖也需要稳定访问，建议参考官方仓库的开发者说明。
